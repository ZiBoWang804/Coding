## 清洗规则

- 统一字段名为搜索词、标题、作者、发布时间、点赞数、详情链接、封面链接等标准列。
- 去掉标题、作者、详情链接、封面都为空的无效记录。
- 点赞数统一转换为整数。
- 相对时间按文件抓取日期换算为标准日期。
- 详情链接优先去重，缺详情链接时退回到标题+作者+封面+搜索词组合去重。
