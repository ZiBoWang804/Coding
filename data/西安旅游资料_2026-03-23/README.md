# 西安旅游资料整理

整理日期：2026-03-23

本文件夹按“西安旅游 / 西安附近旅游 / 乡村旅游”整理了可直接用的景点资料，重点保留了：

- 景点名称与地理位置
- 开放时间
- 参考票价
- 简要介绍
- 可直接查看的风景图链接
- 攻略路线与原始来源

文件说明：

- `景点信息汇总.csv`：适合做表格筛选、复制到 Excel。
- `攻略摘要.md`：把市区、周边、乡村三类玩法压成能直接执行的路线。
- `风景图链接.md`：放了可直接打开的景区图片和景区详情页。
- `来源链接.md`：保留了官方站、携程和补充资料链接，后续方便复核。

使用提醒：

- 开放时间和票价都可能临时调整，尤其是旺季、节假日、演出联票、索道和景交车。
- 表格里的“参考票价”适合做前期筛选；真正下单前，建议再点开对应官方页或携程页核一次。
- 乡村旅游类目的门票规则最容易变，常见情况是“免费入园，但演艺/体验/摆渡/套票单独收费”。
