# 游乡记数据库完整版启动教程

这份教程适合下面这类人：

- 想把项目完整跑起来
- 想让收藏、打卡、社区、搜索历史、后台统计这些功能真的保存到数据库
- 不想只停留在演示模式

这份教程默认按 Windows 电脑来写，并且继续沿用项目里已经自带的 Node 运行环境，所以你依然不需要自己单独安装 Node.js。

## 一、完整版和演示模式有什么区别

### 演示模式

演示模式适合快速看页面。

它的优点是：

- 启动快
- 不需要数据库
- 不需要先安装 PostgreSQL

但它的缺点也很明显：

- 收藏、去过、想去不一定真正保存
- 景点打卡、社区发帖、评论、点赞不完整
- 搜索历史、个性化推荐、后台统计不完整
- 投稿审核和热力图更像展示，不是完整闭环

### 数据库完整版

数据库完整版才是更接近真实可用状态的版本。

接上数据库后，这些功能会完整很多：

- 用户注册与登录
- 收藏、想去、去过
- 景点打卡
- 景点社区发帖、评论、点赞
- 搜索历史
- 个性化推荐
- 用户投稿
- 管理员审核投稿
- 后台统计
- 景点热力图
- 导入数据后真正写入数据库

## 二、你需要提前准备什么

完整版最关键的前提只有一个：

你电脑里要先装好 PostgreSQL，并且让它处于运行状态。

你需要准备的内容如下：

1. 这个项目完整文件夹
2. 已安装好的 PostgreSQL
3. 你自己记得住的 PostgreSQL 密码

## 三、先安装 PostgreSQL

如果你电脑里还没有 PostgreSQL，请先去 PostgreSQL 官网下载安装程序，然后按默认方式安装。

安装时你重点记住两件事：

- 用户名，一般默认是 `postgres`
- 你自己设置的数据库密码

如果安装过程里让你选端口，通常保持默认的 `5432` 就可以。

安装完成后，建议先确认 PostgreSQL 服务已经正常启动。

如果你电脑里安装了 pgAdmin，也可以顺手打开一下，确认能登录进去。

## 四、先创建项目要用的数据库

这个项目默认使用的数据库名是：

`youxiangji`

### 最简单的创建方式

打开 pgAdmin，然后：

1. 连接本地 PostgreSQL
2. 找到左侧 `Databases`
3. 右键
4. 选择 `Create`
5. 选择 `Database...`
6. 数据库名称填写 `youxiangji`
7. 保存

### 如果你会用 SQL，也可以直接执行

```sql
CREATE DATABASE youxiangji;
```

## 五、配置项目的 `.env`

项目根目录里已经有一个 `.env.example`。

你需要让项目根目录里有一个 `.env` 文件。

如果还没有 `.env`，就复制一份：

```bat
copy .env.example .env
```

或者更简单一点，直接双击我给你加的：

`2-初始化数据库-完整版.cmd`

如果发现没有 `.env`，它会自动帮你创建，并打开记事本让你编辑。

### `.env` 里最关键的几项

你至少要确认下面这两项：

```env
DATABASE_URL="postgresql://postgres:你的数据库密码@localhost:5432/youxiangji?schema=public"
USE_DEMO_DATA="false"
```

### 你需要怎么改

如果你的 PostgreSQL 用户名就是默认的 `postgres`，端口也是默认 `5432`，那你通常只需要改密码这一段：

```env
DATABASE_URL="postgresql://postgres:你自己的密码@localhost:5432/youxiangji?schema=public"
```

### 如果你的实际情况不一样

那就按你的实际情况改：

- 用户名不是 `postgres`，就改成你的用户名
- 端口不是 `5432`，就改成你的端口
- 数据库名不是 `youxiangji`，就改成你实际建的数据库名

### AI 相关配置要不要改

可以先不改。

即使你没有配置这些内容，数据库完整版也能正常使用大部分功能：

- `ARK_API_KEY`
- `OPENAI_API_KEY`

它们主要影响更高级的 AI 增强能力，不影响数据库本身。

## 六、初始化数据库

这一步是把表结构和示例数据写进 PostgreSQL。

对新手来说，最简单的方法就是双击：

`2-初始化数据库-完整版.cmd`

它会自动做 3 件事：

1. 生成 Prisma 客户端
2. 把表结构写入 PostgreSQL
3. 导入项目自带的示例数据

### 这一步成功后，你会得到什么

- 基础景点数据

- 一个普通演示用户
- 一部分社区帖子、评论和打卡数据

### 初始化成功后可直接使用的账号

管理员账号：

- 邮箱：`admin@youxiangji.local`
- 密码：`admin123456`

普通演示用户：

- 邮箱：`demo@youxiangji.local`
- 密码：`demo123456`

## 七、启动数据库完整版

初始化完成后，双击：

`3-启动项目-数据库完整版.cmd`

它会：

- 使用项目自带的 Node 运行环境
- 以数据库模式启动项目
- 自动打开浏览器
- 默认访问地址为 `http://localhost:3000`

### 启动后要注意

- 黑色窗口不要关
- 只要你想继续使用项目，就让这个窗口保持打开
- 关掉黑色窗口，项目就会停止

## 八、第一次启动后，建议你这样验证

为了确认你真的跑的是数据库完整版，而不是演示模式，建议按下面顺序检查。

### 检查 1：普通用户登录

打开：

`http://localhost:3000/login`

用下面账号登录：

- 邮箱：`demo@youxiangji.local`
- 密码：`demo123456`

如果登录成功，说明数据库里的用户已经正常读到了。

### 检查 2：管理员登录

打开：

`http://localhost:3000/admin/login`

用下面账号登录：

- 邮箱：`admin@youxiangji.local`
- 密码：`admin123456`

如果能进后台，说明管理员账号也已经正常写入数据库。

### 检查 3：测试“收藏/去过/想去”

进入任意一个景点详情页。

点击：

- `想去`
- `去过`
- `收藏`

然后刷新页面，或者退出后重新登录看状态是否还在。

如果还在，就说明数据库保存正常。

### 检查 4：测试打卡和社区

还是在景点详情页里：

- 写一条打卡内容
- 发一篇帖子
- 再给帖子写一条评论

刷新后如果仍然存在，就说明数据库写入正常。

### 检查 5：测试后台统计

进入管理员后台后，你应该能看到：

- 注册用户数
- 社区帖子数
- 打卡记录数
- 待审投稿数

这些数字如果不是全空，说明数据库版已经真正跑起来了。

## 九、完整版里每个主要功能怎么用

## 1. 用户端

### 注册

入口：

`/register`

你可以直接注册新的普通用户账号。

注册后，数据会真正进入数据库，不再只是临时演示。

### 登录

入口：

`/login`

普通用户必须从这个入口登录。

管理员账号不能从这里登录，否则系统会提示去后台登录页。

### 我的行程

入口：

`/me`

这里可以真实保存：

- 昵称
- 常住城市
- 头像链接
- 个人简介
- 偏好标签

同时还能看到：

- 最近搜索历史
- 个性化推荐
- 自己提交的景点投稿

## 2. 景点详情页

景点详情页在完整版里比演示模式更重要，因为很多互动功能都在这里。

你可以操作：

- `想去`
- `去过`
- `收藏`
- `提交打卡`
- `发布到社区`
- 评论
- 点赞

这些操作在完整版里都会真正写入数据库。

## 3. 智能规划

入口：

`/planner`

数据库版和演示版相比，差别主要在于：

- 可结合更完整的景点数据
- 会记录用户搜索历史
- 后续个性化推荐会更有依据

如果你还额外配置了 AI Key，规划结果会更完整。

如果没有配置 AI Key，也仍然可以正常使用基础规划逻辑。

## 4. 管理员后台

入口：

`/admin`

管理员后台里你可以做这些事：

- 查看概览数据
- 查看浏览趋势
- 查看景点热力图
- 新增景点
- 删除景点
- 审核用户投稿
- 进入导入中心

### 导入中心

入口：

`/admin/import`

这里支持：

- 上传 `CSV`
- 上传 `XLSX`
- 字段映射
- 导入预览
- 确认导入

完整版里导入后的数据会真正进入 PostgreSQL。

## 十、如果你想重新导入一遍数据库

### 最稳妥的方法

如果你只是想重新初始化一遍，最简单的思路是：

1. 先备份你要留的数据
2. 清空或重建数据库
3. 再重新执行 `2-初始化数据库-完整版.cmd`

### 什么时候需要重新初始化

一般只有下面几种情况才需要：

- 你第一次配置错了数据库
- 你想把示例数据重新恢复成初始状态
- 你改了 Prisma 表结构，想重新推一次

## 十一、最常见的问题

### 1. `prisma:push` 失败

最常见原因有 4 个：

1. PostgreSQL 没有启动
2. `.env` 里的密码写错了
3. 数据库名 `youxiangji` 还没有创建
4. 端口不是 `5432`，但你没改 `DATABASE_URL`

先按这 4 项逐个检查。

### 2. 初始化成功了，但登录失败

先确认你是不是用了正确入口：

- 普通用户去 `/login`
- 管理员去 `/admin/login`

再确认账号密码是否正确：

- 普通用户：`demo@youxiangji.local / demo123456`
- 管理员：`admin@youxiangji.local / admin123456`

### 3. 我已经配了数据库，为什么看起来还是像演示模式

重点检查 `.env`：

```env
USE_DEMO_DATA="false"
```

如果这里还是 `true`，那项目还是会走演示模式。

### 4. 为什么我没有看到 AI 联网增强效果

数据库完整版和 AI 完整版不是一回事。

你接上数据库以后，用户数据、互动数据、后台数据会完整。

但如果你还想获得更强的实时 AI 规划能力，你还需要额外配置：

- `ARK_API_KEY`
或
- `OPENAI_API_KEY`

### 5. 为什么我不建议新手先跑 `npm run prisma:migrate`

因为这个项目当前没有现成的 `migrations` 目录。

对新手来说，最稳妥的做法是直接用：

```bash
npm run prisma:push
```

它更适合你现在这个项目的初始化方式。
